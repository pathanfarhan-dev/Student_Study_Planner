# Student Study Planner — Project Report

## 1. Project Objective

The objective of this project is to develop a responsive and interactive Student Study Planner website that helps students organize their study sessions, manage tasks, and track their progress.

## 2. Project Overview

The Student Study Planner provides a simple dashboard where students can add, view, edit, complete, and delete study sessions. Users can organize sessions by subject, date, time, duration, and priority. Search and filtering features make it easier to find specific sessions. The website is designed to work on desktop, tablet, and mobile screens.

## 3. Technologies Used

- HTML5 for webpage structure and semantic elements.
- CSS3 for styling, layout, Flexbox, Grid, and responsive design.
- JavaScript for interactivity, form validation, search, filtering, and session management.
- LocalStorage for saving study sessions in the browser.
- Git for version control.
- GitHub for repository hosting and collaboration.
- GitHub Pages for website deployment.

## 4. Main Features

The website includes a study dashboard, session management form, search and filter options, completion tracking, subject overview, and responsive navigation. JavaScript updates the dashboard dynamically, while LocalStorage preserves session data in the same browser.

## 6. Challenges and Solutions

One challenge was organizing the project into separate HTML, CSS, and JavaScript files. This was addressed by creating a clear folder structure and linking the files correctly. Another challenge involved using Git commands to commit changes and upload the project to GitHub. These steps helped develop practical version-control skills. Testing the website on different screen sizes also helped verify its responsive layout.

## 7. Learning Outcomes

Through this project, I gained practical experience in semantic HTML, CSS layouts, responsive web design, JavaScript DOM manipulation, event handling, form validation, and browser LocalStorage. I also learned how to create a Git repository, maintain commit history, upload files to GitHub, and deploy a website using GitHub Pages.

## 8. Future Improvements

Possible future improvements include user authentication, cloud-based data storage, reminders, calendar integration, and synchronization across multiple devices.
