# StudyFlow — Student Study Planner

## About the Project

StudyFlow is a responsive student study planner built using HTML, CSS, and JavaScript. It helps students organize their study sessions, manage priorities, and track their learning progress.

## Features

- Add, edit, and delete study sessions.
- Mark sessions as completed or pending.
- Search sessions by title, subject, and notes.
- Filter sessions by status and priority.
- Track total, completed, and pending sessions.
- View completion progress and subject statistics.
- Save sessions in browser local storage.
- Responsive layout for desktop, tablet, and mobile screens.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a browser.
4. Add study sessions and explore the features.
